# Flipy

Flipy is a commandline tool to filter files or standard input and return the results in seperat outputs. It offers the option to define several profiles for different usecases

## Motivation

While greping often is enough to get some basic text operations done, Flipy attempts to offer a more automatic approach after a little bit of configuration. Working with massive log files? Flipy allows you to configure a profile to filter out exactly what you need for your debugging process.

Flipy is a reimplementation of a tool I wrote for my old workplace. Its main usecase was to filter lists of emails.
